# Cookie Clicker Clone

A dependency-free Cookie Clicker-style browser game built in committed MVP slices.

## Run

Open `index.html` directly in a browser, or serve the folder locally:

```sh
python3 -m http.server 51913 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:51913/`.

## Current Slice

Slice 1 provides the playable spine:

- Big clickable Cookie
- Cookie total
- Click Power
- Cookie Production engine
- Autosave
- Reset control
